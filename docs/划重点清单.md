# 划重点清单 —— 哪些要背、哪些看一眼、哪些直接跳过

> 配套《代码导读手册》（大话风格，第 0~9 章）、《面试问答手册》（提前练题）、《术语速查卡》（查名词）。
> 用法：每学完一章回来打钩；面试前 3 天用最后一节的方法过一遍。
> 一句话目标：**你不需要学完 2300 行——能讲"400 行核心"+ 会演示，就是高分。**

---

## 一、必会（能用自己的话讲 1~3 分钟）

| # | 必会内容 | 一句话自测 |
| --- | --- | --- |
| 1 | 程序整体怎么跑 | 上电 → key_init/ui_init → `while(1){ ui_task(); }`；按键和蜂鸣器在 SysTick 中断里跑 |
| 2 | 按键怎么读 | 上拉→按下=0；消抖=连续核对 20ms；事件进队列给主循环 |
| 3 | 密码怎么存 | Flash"账本"（魔数+校验和），掉电不丢；默认 1234 |
| 4 | 怎么判断对错 | 位数 + 逐位比对；对→绿灯叮咚；错→红灯嘟呜 |
| 5 | 锁定逻辑 | 错 3 次锁 30 秒；**到期不清零、只再给 1 次；输对才清零**（v0.7.3 改过，有故事！） |
| 6 | OLED 怎么显示 | 先画在显存里 → 整屏推给屏幕；汉字走 16x16 字库 |
| 7 | 灯和蜂鸣器怎么控制 | 拉低=灯亮；PWM 频率=音调（能指出在哪个文件即可） |

## 二、会一句话就行（不追问就不展开）

- `oled.c`：显存是"页格式"，一个字节 = 一列 8 个像素；汉字 UTF-8 占 3 字节。
- `clock.c`：数秒走时；每分钟存一次 Flash；断电最多丢 1 分钟。
- `settings.c`：和时钟同一套"账本"；读的时候验校验和和数字合法性。
- `buzzer.c`：音序表排队播放；换曲子前先"停播"防打架。
- `led.c`：极性集中在两个 write 函数里，改接法只改那里。
- 具体数字忘掉没关系：菜单 30 秒回主页、结果展示 2 秒、消抖 20ms——可以说"我可以现场翻代码给你看"。

## 三、明确"不用会"（放心跳过，别浪费时间）

- ❌ CubeMX 生成的一切：main.c 底稿、it.c 的异常处理、HAL 库内部实现；
- ❌ 字库数据本身（oledfont*.h 里成百上千个十六进制数字）；
- ❌ 数学/编码细节：蔡勒公式推导、UTF-8 编码规则、PWM 占空比公式；
- ❌ 具体地址与寄存器（如 0x0800F800）——知道"存在 Flash 里"就够了。

> 万一被问到上面这些：诚实 + 框架感，比如"这是脚本生成的底层数据，我理解它的格式和生成方式，具体字节没有背"——**这比硬背错答案好得多**。

## 四、五个追场景（每走通一个，把握 +20%）

| # | 场景 | 能说出这些就算过 | 对应章节 |
| --- | --- | --- | --- |
| 1 | 开机上电 | HAL 底座 → `key_init`/`ui_init` → 第一屏是 `ui_draw_page` + `oled_refresh` 画的 | 第 1~2 章 |
| 2 | 按一下 UP | PA0 拉低 → `key_tick`（5ms 扫描 / 20ms 消抖）→ 队列 → `ui_task` → 数字 +1 → `s_dirty` → 重画 | 第 2~3 章 |
| 3 | 输对密码 | OK 逐位确认 → 长按提交 → `settings` 读出密码比对 → 绿灯 + 叮咚 → 2 秒后清空 | 第 3、7、8 章 |
| 4 | 错 3 次锁定 | 计数 +1 → 写 Flash → 第 3 次进锁定 → 红灯慢闪 + 倒计时 → 断电重启仍然锁 | 第 6~8 章 |
| 5 | 修改密码 | 输两遍 → 一致才写 Flash + 次数清零 → 自动回密码锁页；断电后新密码生效 | 第 7~8 章 |

## 五、面试前 3 天怎么用

| 时间 | 做什么 |
| --- | --- |
| 前 3 天 | 把"必会 7 条"每条讲一遍（录音听一遍，或讲给我/朋友听） |
| 前 2 天 | 走一遍"五个追场景" + 做模拟题（找我"出题"） |
| 前 1 天 | 只看"必会" + "七个一句话"；把演示彩排 2 遍（含锁定功能展示） |
| 当天上午 | 边走边默念：演示流程 → 七句话 → 三问答案（GPIO/消抖/I2C） |

> 记住：考的是"**真的做过、真的理解**"，不是"背得多"。你两样都占了。
