# 术语速查卡 —— 名词忘了？一查就有

> 用法：读代码/看手册卡在某个名词上，先来这里找；解释只有一两句，想深入看"细讲"那一章。
> 原则：**先听懂人话，再记术语**——术语只是给懂了的东西起个名字。

| 术语 | 一句话人话解释 | 细讲 |
| --- | --- | --- |
| GPIO | 单片机上一个个可读可写的引脚 | 第 1 章 |
| 上拉 / 下拉 | 给引脚一个"默认电平"（高 / 低），防止悬空乱飘 | 第 1 章 |
| 浮空 | 引脚什么都不接，电平不确定（像没系住的绳子） | 第 1 章 |
| 推挽输出 | "有推有拉"：引脚能主动输出高或低 | 第 1 章 |
| 开漏输出 | "只能拉低，或者放手"：高电平靠外部拉上去 | 第 1 章 |
| 高阻态 | 引脚"放手"的状态，相当于断开 | 第 1 章 |
| I2C | 两根线的通信方式（SCL 时钟 + SDA 数据） | 第 1、4 章 |
| PWM | 方波；频率和占空比可以调 | 第 1、5 章 |
| 占空比 | 一个周期里高电平占的比例 | 第 5 章 |
| 预装载 | 让新参数"排队到下一周期生效"的机制（防波形畸形/爆音） | 第 1、5 章 |
| ARR / CCR | 定时器的两个"旋钮"：频率 / 占空比 | 第 5 章 |
| 中断 | 硬件"打断"CPU、让它先处理小事的机制 | 第 2 章 |
| SysTick | 芯片自带的 1ms 定时中断（整个程序的心跳） | 第 2 章 |
| 消抖 | 连续核对一段时间，过滤按钮弹跳 | 第 3 章 |
| 状态机 | 用"当前状态 + 条件"组织逻辑的写法 | 第 3、8 章 |
| 队列 | "先来先服务"的缓冲区（事件排队） | 第 3 章 |
| 显存 | 画面的内存底稿（1024 字节） | 第 4 章 |
| 页格式 | SSD1306 的显存排布：一个字节 = 一列 8 个像素 | 第 4 章 |
| UTF-8 | 汉字占 3 字节的编码方式 | 第 4 章 |
| Flash | 掉电不丢的存储器（每页约 1 万次擦写寿命） | 第 6 章 |
| 魔数 | 标记"这条记录是什么"的特殊值（如 'PWD1'） | 第 6、7 章 |
| 校验和 | 几个字节相加的"防伪码"，用来发现数据写坏 | 第 6、7 章 |
| 账本式存储 | 新数据往后追加、不覆盖旧的（省擦写次数） | 第 6 章 |
| RTC | 芯片里的"真时钟"（要配电池才能断电也走） | 第 6 章 |
| SWD | 烧录 / 调试口（PA13、PA14），不能占用 | 第 1 章 |
